# docs/

Design documents for VoxScore. Add your Part 2 submissions here so they live next to the code:

- `project-idea-description.pdf`: the two-page idea description
- `wireframes.pdf`: the low-fidelity wireframes and design rationale (exported from the
  "VoxScore Wireframes" design canvas)

The screens in the app follow the wireframes one to one; the table in the main
[README](../README.md#the-screens-from-the-wireframes) maps each wireframe screen to its URL.
